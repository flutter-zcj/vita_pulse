# VitaPulse 脉迹

个人生命体征管家 · Flutter (GetX) + RuoYi-FastAPI

用手机摄像头测心率，日常记录并管理个人生命体征，看趋势、早发现异常。

> ⚠️ 本产品为健康参考工具，非医疗器械。测量结果不能用于诊断或治疗决策。

## 技术栈

| 层 | 选型 |
|---|---|
| 客户端 | Flutter · GetX · Dio · fl_chart · camera |
| 后端 | RuoYi-FastAPI（FastAPI + SQLAlchemy 2.0 + Redis + JWT） |
| 数据库 | PostgreSQL |

## 核心能力

| 能力 | 说明 |
|---|---|
| 摄像头测心率 | 后置摄像头 PPG 算法，30 秒输出心率 / HRV / 呼吸率 |
| 手动录入 | 血氧、血压、体温、体重（摄像头无法测量的指标） |
| 趋势分析 | 日 / 周 / 月曲线，参考区间带 |
| 异常预警 | 自定义阈值，越界提示 |
| 指标配置驱动 | 指标字典由后端下发，新增指标无需发版 |

## 数据边界

| 指标 | 来源 |
|---|---|
| 心率 / HRV / 舒适度 / 压力 | 摄像头 PPG |
| 呼吸率 | 摄像头估算 |
| 血氧 / 血压 / 体温 / 体重 | 仅手动录入，**不做摄像头测算** |

手机单色光源无法完成血氧所需的双波长比值计算，本项目不提供该类估算值。
