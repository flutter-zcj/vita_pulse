# 体征测量准备（用例2）

## 基本流程

1. 用户在首页点击「开始测量」，进入体征测量准备页；
2. 系统检查相机权限状态；
    1. 已授权，直接展示准备页内容；
    2. 未授权，弹出系统权限申请对话框；
3. 系统展示测量操作要点与示意区域，等待用户准备；
4. 用户点击「开始检测」按钮，页面跳转至检测进行中页；
    1. 跳转前将页面状态标记为「本次测量已开始」，并记录开始时间戳；
5. 用户点击导航栏返回按钮，返回首页，不产生任何测量记录。

## 异常情况

1. 相机权限被拒绝：
    1. 页面展示权限说明卡「需要相机权限才能测量」；
    2. 提供「去设置」按钮，跳转系统设置页；
    3. 不展示「开始检测」按钮；
2. 相机权限被永久拒绝：
    1. 提示文案改为「权限已被永久拒绝，请到系统设置中手动开启」；
    2. 仅保留「去设置」按钮；
3. 设备无可用后置摄像头：
    1. 展示「当前设备不支持摄像头测量」提示；
    2. 提供「改用手动录入」按钮，跳转手动录入页；
4. 用户连续快速点击「开始检测」：
    1. 按钮进入防抖状态，300 毫秒内只响应第一次点击；
5. 从检测页返回后再次进入本页：
    1. 重置页面状态，重新检查权限，不复用上次会话数据。

## 业务规则

1. 本页不采集任何数据，不产生测量记录，仅做权限检查与操作引导。
2. 测量时长固定为 30 秒，页面文案须明确告知用户「保持静止约 30 秒」。
3. 相机权限状态每次进入页面均重新校验，不缓存权限结果。
4. 本页须展示免责声明「结果仅供健康参考，不能替代医疗诊断」，字号不小于 12sp，颜色为次级文字色。
5. 三条操作要点固定为：光线充足正对光源、手机放稳轻触屏入镜、检测期间不说话不移动。
6. 进入本页时须关闭上一页可能残留的相机资源，防止相机占用冲突。

## 编码要求

> 本章节为本页面开发实现的强制约束，生成文档时默认必须包含且必须遵守。

### 用户页面要求

1. 页面进入后须在 300 毫秒内完成首帧渲染，无网络请求；
2. 相机权限检查与申请须在进入页面时完成，不得延迟到点击「开始检测」时才申请；
3. 虚线椭圆与圆形示意区使用 `CustomPainter` 绘制，不得使用图片资源；
4. 按钮点击须做 300 毫秒防抖；
5. 页面不读写任何本地存储，不产生测量数据。

### 编码规范基线（默认必须遵守）

1. 遵循项目统一的 Flutter/Dart 编码规范，`flutter analyze` 须零告警；
2. 采用 GetX 模块化结构，页面由 `view / controller / binding` 三件套组成，View 层不写业务逻辑；
3. 数据接口统一通过项目封装的 `ApiClient` 调用，禁止在页面内直接发起 HTTP 请求；
4. 命名规范遵循项目约定（文件 snake_case、类名 UpperCamelCase、常量 k 前缀）；
5. 异常与边界处理遵循项目规范，权限异常须给出可操作的处理入口；
6. UI 组件优先复用项目公共组件，不重复造轮子。
