# 检测结果（用例4）

## 基本流程

1. 页面接收检测进行中页传递的会话数据（心率、HRV、舒适度、压力等级、信号质量分、测量时间）；
2. 系统请求 `GET /vital/record/latest?metric=spo2`，获取最近一次手动录入的血氧值；
3. 系统渲染四项指标卡片：心率、舒适度、心率变异性、血氧；
    1. 心率、舒适度、心率变异性取自本次会话数据；
    2. 血氧取自步骤 2 的返回值，并展示「手动」角标与录入时间；
4. 系统渲染压力水平段位条，按压力等级高亮对应区间；
5. 用户点击「保存记录」，系统调用 `POST /vital/record/batch` 提交本次全部指标；
    1. 保存成功后展示 Toast「已保存」，跳转首页；
6. 用户点击「重新检测」，返回体征测量准备页，丢弃本次数据。

## 异常情况

1. 血氧接口请求失败或超时：
    1. 血氧卡片数值显示 `--`；
    2. 角标文案改为「暂无」；
    3. 不影响其它三项指标展示；
2. 近 30 天内无血氧录入记录：
    1. 数值显示 `--`；
    2. 卡片底部展示「去录入」文字入口，点击跳转手动录入页；
3. 保存接口返回失败：
    1. 保留当前页面全部数值，不清空、不跳转；
    2. Toast 提示服务端返回的 `msg`；
    3. 「保存记录」按钮恢复可点击状态，允许重试；
4. 用户重复点击「保存记录」：
    1. 按钮进入 loading 状态并禁用，直至请求返回；
    2. 已保存成功后再点击，提示「本次记录已保存」并直接跳转首页；
5. 本次测量信号质量分低于 0.35：
    1. 页面顶部展示黄色提示条「本次信号较弱，结果仅供参考」；
    2. 保存时仍写入 `quality` 字段，标记置信度低；
6. 页面在保存过程中被销毁：
    1. 取消未完成的请求；
    2. 下次进入不残留 loading 状态。

## 业务规则

1. 血氧数值**不通过摄像头测算**，一律取最近一次手动录入值；超过 30 天无录入视为无数据，展示 `--`。
2. 心率、心率变异性、舒适度、压力等级由摄像头 PPG 算法产出的会话数据提供，均标记来源为 `camera`。
3. 舒适度为 0–100 的整数评分，数值越低表示身体状态越偏离个人静息基线；展示时只显示整数，不带单位。
4. 压力等级分为五档：很低、较低、中等、较高、很高，当前档位高亮，其余档位置灰。
5. 保存时一条测量会话写入多条 `vital_record` 记录，各条记录携带相同的 `session_id`，便于回溯同一次测量。
6. 保存记录的 `measured_at` 取会话开始时间，`quality` 取本次信号质量分，`source` 固定为 `camera`。
7. 页面须展示免责声明「结果仅供健康参考，不能替代医疗诊断」。
8. 保存成功后不在此页做数据持久化，数据由服务端返回后由首页重新拉取。

## 界面描述

页面背景为浅色（`#FFFFFF`）。顶部为导航栏，左侧返回按钮，中间标题「检测结果」。主体上部为 2×2 指标卡片网格，每张卡片含指标名、大号数值、单位与来源角标；中部为「压力水平」区块，含五段式进度条与当前档位文字；下部为说明小字与免责声明；底部为两个操作按钮，主按钮「保存记录」为实心填充，次按钮「重新检测」为文字样式。

## 编码要求

> 本章节为本页面开发实现的强制约束，生成文档时默认必须包含且必须遵守。

### 用户页面要求

1. 页面首帧须在 200 毫秒内完成，血氧数据异步补齐，不得阻塞其它三项指标展示；
2. 四宫格卡片布局须适配 320dp–430dp 屏宽，不得出现文字截断或换行错位；
3. 压力段位条使用 `CustomPainter` 或分段容器实现，不得使用图片切图；
4. 保存按钮须做防重复提交处理（loading 态 + 禁用）；
5. 页面不读写本地存储，数据通过路由参数传入、通过接口提交。

### 编码规范基线（默认必须遵守）

1. 遵循项目统一的 Flutter/Dart 编码规范，`flutter analyze` 须零告警；
2. 采用 GetX 模块化结构，页面由 `view / controller / binding` 三件套组成，View 层不写业务逻辑；
3. 数据接口统一通过项目封装的 `ApiClient` 调用，禁止在页面内直接发起 HTTP 请求；
4. 命名规范遵循项目约定（文件 snake_case、类名 UpperCamelCase、常量 k 前缀）；
5. 异常与边界处理遵循项目规范，保存失败须保留现场数据并支持重试；
6. UI 组件优先复用项目公共组件（指标卡片、段位条），不重复造轮子。
