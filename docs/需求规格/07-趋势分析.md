# 趋势分析（用例7）

## 基本流程

1. 用户从首页指标卡片或记录列表卡片进入趋势分析页，页面接收指标编码与可选的时间定位参数；
2. 系统调用 `GET /vital/record/stat`，按默认条件（当前指标、近 7 天、按天聚合）请求统计数据；
3. 系统渲染趋势折线图；
    1. 折线下方绘制参考区间带（取自指标字典的 `default_min` 与 `default_max`）；
    2. 纵轴按指标单位自适应刻度，横轴按所选周期展示日期；
4. 系统渲染统计摘要区，展示最小值、平均值、最大值与样本条数；
5. 用户点击顶部时间分段控件切换周期（近 7 天 / 近 30 天 / 近 90 天），系统重新请求并重绘；
6. 用户点击指标下拉切换其它指标，系统重置周期为近 7 天并重新请求；
7. 用户长按折线图任一节点，展示浮层显示该时间点的数值与测量时间；
8. 用户点击浮层外的空白区域，浮层消失。

## 异常情况

1. 统计数据请求失败：
    1. 图表区域展示「加载失败」与「重试」按钮；
    2. 统计摘要区显示 `--`；
2. 该指标在所选周期内无数据：
    1. 图表区域展示空态文案「该周期内暂无数据」；
    2. 提供「切换周期」与「去录入」两个引导入口；
3. 样本数少于 2 条：
    1. 不绘制折线，仅绘制单点圆点；
    2. 展示提示「数据较少，趋势仅供参考」；
4. 指标字典缺失该指标配置：
    1. 参考区间带不绘制；
    2. 仅展示折线与统计值，不阻塞页面；
5. 快速连续切换周期：
    1. 以最后一次选择为准，前序请求结果丢弃（请求序号校验）；
    2. 切换期间展示图表骨架屏。
6. 长按浮层数值为空：
    1. 不展示浮层，避免出现空白气泡。

## 业务规则

1. 聚合粒度随周期自动变化：近 7 天按天聚合，近 30 天按天聚合，近 90 天按周聚合。
2. 折线取聚合后的平均值，统计摘要中的最小值、最大值取原始记录的真实极值，而非聚合值。
3. 参考区间带颜色区分是否越界：区间内为常规色，超出上界的点标红，低于下界的点标蓝。
4. 血压类指标（`dual` 类型）在同一图表中绘制两条折线，收缩压在上、舒张压在下，图例固定展示。
5. 横轴标签数量不超过 7 个，超出时按等间隔抽稀显示。
6. 页面数据不做本地持久化，每次切换条件均重新请求接口；同一条件在同一会话内可复用内存缓存。
7. 图表数值展示精度与指标字典的 `precision` 保持一致。

## 界面描述

## 编码要求

> 本章节为本页面开发实现的强制约束，生成文档时默认必须包含且必须遵守。

### 用户页面要求

1. 图表使用 `fl_chart` 实现，切换周期时须有不超过 200 毫秒的过渡动画；
2. 参考区间带使用 `RangeAnnotations` 绘制，不得使用叠加图片；
3. 切换条件时须做请求序号校验，避免旧响应覆盖新图表；
4. 图表数据点数量超过 90 个时须降采样后再渲染，保证滚动与手势流畅；
5. 页面**不做本地持久化**，切换条件一律请求接口。

### 编码规范基线（默认必须遵守）

1. 遵循项目统一的 Flutter/Dart 编码规范，`flutter analyze` 须零告警；
2. 采用 GetX 模块化结构，页面由 `view / controller / binding` 三件套组成，View 层不写业务逻辑；
3. 数据接口统一通过项目封装的 `ApiClient` 调用，禁止在页面内直接发起 HTTP 请求；
4. 命名规范遵循项目约定（文件 snake_case、类名 UpperCamelCase、常量 k 前缀）；
5. 异常与边界处理遵循项目规范，空数据与少样本须有独立展示分支；
6. 图表配置须抽取为独立 Widget，便于复用与单测。
