```
首页仪表盘 ──开始测量──> 准备 ──> 检测中 ──> 结果 ──保存──> 首页

    ├──点击指标卡──> 趋势分析
    └──去录入────> 手动录入 ──保存──> 返回上一页

记录列表 ──卡片──> 趋势分析
设置 ──预警阈值──> 阈值设置
```

## 全局约束（所有页面适用）

1. **无本地业务数据存储**：不引入 Hive / GetStorage / SQLite；页面数据一律来自接口，进入页面或下拉刷新时请求。
2. **无登录注册**：App 启动时静默完成身份获取，用户无感知。
3. **样式基准**：测量流程为深色（`#0B3133`），结果页与列表页为浅色；主色 `#2ED3BE`。
4. **免责声明**：涉及测量结果的页面必须展示「结果仅供健康参考，不能替代医疗诊断」。
5. **技术栈**：Flutter + GetX + Dio + fl_chart + camera；后端 RuoYi-FastAPI。
